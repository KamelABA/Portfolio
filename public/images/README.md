# Images Folder

Place your project images here. 

## Usage

In the project editor, you can reference images from this folder by entering just the filename (e.g., `my-project.jpg`).

The system will automatically look for images in this folder when you enter a filename.

## Supported Image Formats

- JPG/JPEG
- PNG
- GIF
- WebP
- SVG

## Other Options

You can also:
- **Upload images**: Click "Upload Image" button - images will be stored as base64
- **Use URLs**: Paste any image URL (e.g., `https://example.com/image.jpg`)
- **Use emojis**: Enter an emoji directly (e.g., 🛒)
